# How to present this project

Suggested GitHub repo name:
`smart-transit-fleet-optimizer`

Suggested resume entry:

**SmartTransit: Demand Forecasting & Fleet Optimization | Python, Scikit-learn, Streamlit**
- Built an ML dashboard to forecast route-level passenger demand and generate data-driven bus allocation recommendations.
- Engineered temporal, route and weather features and trained a Random Forest regression model for demand prediction.
- Developed a capacity-based optimization layer to flag routes requiring additional or fewer buses.
- Created an interactive Streamlit interface for route analysis, fleet planning and model evaluation.

Suggested GitHub description:
`ML-powered transit demand forecasting and route-level fleet planning dashboard.`

Important: the included data is synthetic. Do not claim that the project uses official BMTC data or produced actual BMTC savings.
